# Visual system

Operate mode. A restrained financial statement: warm paper background, dark green navigation and primary actions, generous whitespace around forms, tabular numerals for money, thin rules separating activity. Public Sans for interface text. No invented charts, decorative data, or lab jargon in wallet screens.

Use accessible labels and focus rings. Keep a visible Demo — fake funds label. Desktop navigation becomes a wrapping top bar on mobile; forms remain single column. Errors and loading states occupy real layout space. Icons, if needed, use simple consistent SVG geometry.
