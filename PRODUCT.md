# SecureWallet

A local digital-wallet AppSec assessment lab for a learner preparing for entry-level security interviews. All funds are fake INR. The normal interface serves wallet users; developer explanations belong in documentation. Separate, opt-in vulnerable fixtures demonstrate intentionally introduced flaws.

Platform: responsive web, Next.js + Express + PostgreSQL. Core user tasks: sign in, inspect balance, transfer money, inspect history, and request support. Admins review users, support, transfers, and audit events without editing balances.

The supplied brief is the product authority. Inferred presentation choice: a quiet, light interface suited to sustained reading and a live interview demo; forest green, warm neutral surfaces, clearly labeled forms. User authorized routine implementation choices and requested implementation, so no separate design approval is required.
